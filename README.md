# ETF配息通 (`etf-stock`)

專為個人打造的台股 ETF 配息追蹤與現金流儀表板，採用深墨綠毛玻璃手機版介面設計（支援 PWA 加入主畫面）。

## 核心功能

- **動態總覽**：顯示「下一筆預估入帳」、本月入帳明細（區分已到發放日與待發放）、年度入帳長條圖。
- **除息資格自動判斷**：依各筆買賣紀錄的交易日期嚴格比對 `交易日期 < 除息日`，自動排除除息日當天或之後才買入的期別。
- **除息與發放行事曆**：支援「全部熱門 ETF」與「只看我的持股」篩選。
- **自選與買賣紀錄管理**：即時計算目前持股、平均成本、預估年配息與殖利率，所有紀錄自動儲存於瀏覽器 `localStorage`。
- **熱門 ETF 排行**：依年化殖利率、配息頻率、年配金額排序，支援一鍵新增持股。
- **JSON 備份與還原**：免登入、免 Firebase 即可匯出與匯入交易紀錄。

## 快速預覽與部署

本專案為純靜態網頁（HTML + CSS + Vanilla JS），無需任何建置工具即可運行：

1. **GitHub Pages**：在 Repo 的 `Settings -> Pages` 選擇 `main` 分支根目錄即可免費上線。
2. **Vercel**：匯入此 GitHub Repo 即可自動部署，後續也可擴充 Vercel Serverless Functions 串接 TWSE 證交所即時股價與配息公告。
3. **手機使用**：部署上線後，以手機瀏覽器開啟網址並選擇「加入主畫面」，即可當作原生 App 使用。
